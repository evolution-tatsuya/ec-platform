## 🔍 発見した重要事項

### イベント管理ページの仕様
- **イベント未登録時**: `AdminEventsPage.tsx` の354-363行目で、イベントが存在しない場合は「イベントが登録されていません」メッセージのみ表示
- **タイトル・タブ非表示**: イベントが存在しない場合、ページタイトルや3つのタブ（フォーム作成、参加者リスト、QR受付）は表示されない
- **期待される動作**: これは意図された設計であり、テストはこの仕様を正しく処理する必要がある

### テスト設計のポイント
- **条件分岐処理**: データ存在確認 → 存在する場合のみ詳細テスト実行
- **スクリーンショット分析**: 失敗時は必ずスクリーンショットを確認してページの実際の状態を把握
- **待機戦略**: `networkidle` + 追加の2秒待機で安定性向上
