## 🔍 問題分析

### 主なエラー原因

1. **ページタイトル・ボタンの表示遅延**
   - TC-A008-001で「軸を追加」ボタンが5秒以内に表示されない
   - レスポンシブテストでも同様の問題が発生
   - **原因**: API読み込み遅延またはローディング処理の問題

2. **軸追加ダイアログ関連のタイムアウト**
   - TC-A008-009, TC-A008-010, TC-A008-011で60秒タイムアウト
   - **原因**: ダイアログが開かない、または入力フィールドが表示されない

3. **レスポンシブ表示の問題**
   - ビューポート変更後にコンテンツが再レンダリングされない可能性
   - **原因**: ページ読み込み完了前にビューポート変更している可能性

## 💡 推奨される修正方針

   - `waitForLoadState('networkidle')`後に追加のwaitを設定
