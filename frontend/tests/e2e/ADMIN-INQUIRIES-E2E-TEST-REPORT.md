## 📝 テスト実行時の注意事項

### データ状態
- 問い合わせデータが0件の状態でテストが実行された
- そのため、詳細ダイアログのテスト（TC-008〜TC-016）は「詳細ボタンが見つかりません」と表示されているが、テストとしてはPass扱い
- AI使用状況タブはダミーデータで表示されているため、グラフやカードは正常に表示されている

### MUI Selectの問題
- MUI v6のSelectコンポーネントで、`input`要素をクリックしても、実際には`div[role="combobox"]`要素がインターセプトしてクリックイベントが届かない
- 修正方法: `div[role="combobox"]`要素を直接クリックする、または`page.selectOption()`を使用する

### 推奨される修正
```typescript
// 現在のコード（失敗）
const selectInput = statusFilter.locator('input, select').first();
await selectInput.click();

// 修正後のコード（推奨）
const combobox = statusFilter.locator('[role="combobox"]').first();
await combobox.click();
```
