# 商品管理ページ（AdminProductsPage）E2Eテスト仕様書

最終更新: 2026-05-01

---

## 📋 テスト対象ページ

**ページ名**: 商品管理（Admin Products Page）
**URL**: `/admin/products`
**権限**: 管理者のみ
**目的**: 商品の登録・編集・削除、在庫管理ができること

---

## 🎯 テストスコープ

### ✅ 対象機能（TC-001～TC-005は完了済み）
- TC-006～TC-024: UIフローとインタラクション

### ❌ 対象外
- API接続のモック（実際のAPIを使用）
- Prismaスキーマのバリデーション
- React Queryキャッシュの内部挙動

## 🧪 テストケース一覧（TC-006～TC-024）

### グループ1: 商品登録・編集ダイアログ（6項目）

#### TC-006: 新規商品登録ダイアログの表示
**優先度**: 高
**実行時間**: 約10秒

**テストフロー**:
1. `/admin/products`にアクセス
2. [新規商品追加]ボタンをクリック
3. ダイアログが開くことを確認
4. タイトルが「新規商品追加」であることを確認
5. 全フォーム項目が表示されることを確認
   - 商品名（TextField）
   - 価格（TextField、type="number"）
   - 初期在庫数（TextField、type="number"）
   - 商品説明（TextField、multiline）
   - 商品種別（Select）
   - カテゴリータイプ（Select）
   - 画像アップロード（Button + input[type="file"]）
   - 準備日数（TextField、type="number"）
6. [キャンセル]ボタンと[登録]ボタンが表示されることを確認

**期待結果**: ✅ ダイアログが開き、全フォーム項目が正しく表示される

## 🎯 実装時の注意点

### 1. 一括操作機能の実装不足
現在の実装では、一括公開・非公開・削除機能が`console.log`のみで実装されていません。
**対応**: API実装後にテストを実行してください。

### 2. 商品種別による動的UI変更
外部URL入力欄が商品種別に応じて表示/非表示されるべきですが、現在は常に表示されています。
**対応**: 実装を改善するか、テストケースTC-007をスキップしてください。

### 3. React Queryキャッシュ
削除や更新後、React Queryのキャッシュによりすぐに反映されない場合があります。
**対応**: `waitForResponse()`や`waitForLoadState('networkidle')`を使用してください。

### 4. 削除テストのデータ依存性
TC-012（商品削除）は、注文に紐付いていない商品を使用する必要があります。
**対応**: テストデータを事前に準備してください。
